# Security policy

Report suspected vulnerabilities privately to [hello@livewyer.com](mailto:hello@livewyer.com). Do not open a public issue containing vulnerability details.

Include the affected version or commit, the component involved, reproduction steps and the impact you observed. A minimal request or sample is useful. Remove credentials, access tokens, cookies, personal data and signed media URLs from all examples and logs. Signed URLs grant access until they expire.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/livewyer-ops/cf-tams/issues).
